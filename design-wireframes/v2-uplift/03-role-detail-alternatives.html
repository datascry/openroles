Role detail

Today's role page is a single 65 ch column with the title, six metadata items run together with mid-dots, an apply button, and a description excerpt — also using stale token names (--color-muted, --font-size-3) that no longer exist in the Brutalist Press system. Each alternative below treats the page as the conversion surface it is, while staying inside the broadsheet aesthetic.
